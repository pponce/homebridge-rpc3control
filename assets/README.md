# RPC PDU Control icon

- `homebridge-rpc3control-icon.png`: 100 × 100 PNG for the Homebridge verification/icon request.
- `homebridge-rpc3control-icon-512.png`: 512 × 512 PNG for larger displays.

Concept: a graphite rack PDU with eight cream sockets, a green power symbol, and a deep plum app tile. This is project artwork, not a Homebridge verification badge or an official BayTech/Homebridge logo.

Generated using the built-in image-generation tool, then exported at the required sizes. The generated original remains separate; the files here are the project assets. These icons are covered by the repository's MIT license.

Homebridge manages the plugin search-card icon through its verification/icon request process. Merely adding these files to the repository or npm package does not register the icon. See [VERIFICATION.md](../VERIFICATION.md).

## Generation prompt

One final icon, no presentation sheet. A prominent mint-green power symbol in a dark circular button overlaps the lower right corner of the unit. Background: solid deep plum rounded-square app tile, with tasteful very subtle depth and generous outer spacing. Crisp vector-like shapes, restrained highlights, strong silhouette, friendly premium utility-app feel, legible downscaled to 100x100 pixels. No text, no letters, no watermark, no checkmark, no Homebridge or Apple logo, no verification badge, no extra objects. Output a square PNG master with the icon filling the canvas.
